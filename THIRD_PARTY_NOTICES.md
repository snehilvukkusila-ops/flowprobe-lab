# Third-party notices (FlowProbe Lab)

Every file copied from outside this repository is listed here with its source URL, pinned
commit, licence and what was taken. Upstream licence files are kept in `LICENSES/`.
Nothing is fetched at runtime. Upstream scripts are never run except `npm ci --ignore-scripts`
and `vite build`.
